# Standard playing-card artwork

These 54 SVG faces are static renderings of `@letele/playing-cards` 0.1.0,
which adapts Adrian Kennard's print-ready playing cards:

- Original artwork: https://www.me.uk/cards/
- React conversion: https://github.com/letele/playing-cards
- License: CC0 1.0 Universal (see LICENSE.txt)

The ace of spades has been simplified by removing the original QR code,
decorative outlines and website text. Source attribution is kept here, not
printed on the user's cards.

Faces are served locally, with no external image/CDN dependency. Card backs
are separate original vector patterns in src/cards.jsx. None of the Google
Drive reference files have been copied into this repository.
