# 啤牌工房 · Card Studio

簡單、快速的啤牌製作工具。React + Vite，沒有後端，圖片不會上傳到伺服器。

## 使用

1. 選 52 張啤牌、54 張（連大小皇）、108 張 UNO 類型，或 1–160 張自訂卡。
2. 選 **純啤牌 / 小 LOGO / 完整圖片 / 加入文字**。可以套用整副，亦可只改一張。
   - **小 LOGO**：預設 **18 mm**（可調 5–45 mm），提供**保留中間花色**（可放正中央、下方中央、右上、左下）或**取代正中間花色（占圖正中央位置）**的選擇。
   - **完整圖片**：支援填滿裁切、完整顯示、白邊、可選角標，以及**正中間花色要不要顯示**（想似啤牌可選「顯示正中間花色」，不想擋圖案可選「不顯示」）。
   - **加入文字（純文字）**：文字置中放大並可調校文字大小（60%–220%），可自由選擇**取代正中間花色**、**顯示中間花色**或**不顯示牌面**，亦可開關四角點數角標。
   - 選「只改這張」後，可多選圖片，從目前卡牌起按選取順序加入。
3. 選經典、菱格、交織、淨色牌背，或上傳自己的完整牌背。全副共用同一牌背。
4. 選擇紙張與每張紙印幾張牌，看雙面排版，再列印 / 存 PDF。建議先試印第一張紙。

## A4 與 3R 雙面列印

- **A4 直向**：可自由選擇 1 張 A4 紙上印幾張牌（預設 9 張，可選 1、2、4、6、8、9、12、16、18、20、25、36、52 或自訂 1–160 張）。
  - 1–9 張時維持標準 **63 × 88 mm** 尺寸；超過 9 張時按 63:88 比例自動計算最佳網格與卡牌尺寸。
- **3R 相片紙（89 × 127 mm）**：預設每張印 **2 張卡**（橫放 2 × 1，每張正正是標準卡牌大小 **63 × 88 mm**），亦可切換為每張 1 張卡。
- **4R 相片紙（102 × 152 mm）**：預設每張印 **2 張卡**（標準 63 × 88 mm），亦可切換為每張 1 張卡。
- PDF 依序為 **正面 1、反面 1、正面 2、反面 2…**。
- **長邊翻頁**：牌背位置左右對位，圖案本身不鏡像。
- **短邊翻頁**：位置上下對位，並將各牌背旋轉 180°，保持成品方向一致。
- 最後一頁保留空白格；牌背空格也會對位，不會把剩餘牌背集中在左上。
- 裁切標記只印在正面；正反頁的微小頁碼在牌外。
- 牌背左右 / 上下偏移可微調 ±3 mm，以補償家用打印機的進紙誤差。

**重要：網頁不能替你開啟打印機的實際雙面選項。** 在列印視窗選：

1. 雙面列印，翻頁方式與工房設定一致（建議長邊）。
2. 原尺寸 / 100%，不要「符合頁面」。
3. 開啟背景圖形，關閉瀏覽器頁首頁尾。

PDF 已排好頁序，但家用打印機不能保證零偏差。先試印正反一張，再裁切或微調。
沒有自動雙面功能，可先印奇數頁，再按機款入紙方向重放並印偶數頁；部分機款需逆序。

## 素材與瀏覽器儲存

- 內置 54 張本地 SVG 牌面，採用 Adrian Kennard 的 CC0 印刷卡牌；來源與授權在 `public/cards/`。葵扇 A 的原網站字句及 QR 圖案已移除，來源資訊只放在說明檔。
- 牌背是原創的 180° 對稱 SVG 花紋，預設沒有大 Logo、應用程式圖示或牌組名稱。
- PNG / JPG / WEBP / GIF / SVG，每圖上限 20 MB。GIF 使用首幀；SVG 會本地光柵化。大圖長邊縮至最多 2000 px，保留足夠列印解像度。
- **瀏覽器儲存之前設計**：除了自動儲存目前工作進度外，可按「存入瀏覽器」或開啟「我的設計」將多份設計儲存在瀏覽器（IndexedDB / localStorage），隨時載入、更新或刪除之前的設計。
- 換裝置 / 清除瀏覽器前，亦可「匯出 JSON」下載備份，再「匯入 JSON」。支援新版及舊版 JSON / localStorage 卡牌資料，保留原有上傳圖片。
- 復原 / 重做保留最近 30 次操作。快捷鍵：Ctrl/Cmd + Z、Shift + Ctrl/Cmd + Z、Ctrl/Cmd + S 存入瀏覽器。
- 中文字型及卡牌圖案本地提供，不依賴 Google Fonts / 外部圖片 CDN；字型授權保存在 `public/fonts-LICENSE.txt`。

## 開發與驗證

```sh
npm ci
npm run dev                 # 0.0.0.0:5173，允許 Arena 預覽 host
npm run build
npm test                    # 牌組、匯入、安全值及雙面對位單元測試
npx playwright install --with-deps chromium
npm run test:e2e            # Chromium 真實操作、PDF 頁數及尺寸、圖片、手機版
```

已有系統 Chromium 時，可指定 `CHROMIUM_EXECUTABLE_PATH=/path/to/chromium npm run test:e2e`。

`src/print-layout.js` 是單一的正反配對 / 空格 / 紙張幾何來源；螢幕排版預覽及列印使用相同的 `PrintPage` 和 `PlayingCard` 元件。
